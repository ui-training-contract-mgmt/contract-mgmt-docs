# 4. Internationalization

## Read

- [NGX Translate](https://github.com/ngx-translate/core)

## Practice

1. Install ngx-translate:

```
npm i @ngx-translate/core @ngx-translate/http-loader
```

2. Implement:

| What | Business description |
|------|----------------------|
| Setup | Register ngx-translate for the whole app. Texts are loaded from files; the app starts in English and falls back to English for missing keys |
| Translation files | One file per language, English and German, in the public folder. Keys are grouped by feature (for example navigation, login, contracts) |
| Language service | A service that knows the current language, switches between English and German and remembers the choice in localStorage for the next visit |
| Language switch | A button that shows the other language and switches on click. It is added to the header in the login chapter |
| First page | The title and the button of chapter 2 now use translation keys |
| Convention | From now on no visible text is hard-coded: every label, button, message and column header is a key in both files |

3. Switch the language in the browser, reload and check that the choice is kept.

## Tests

- The first page shows the translated title and button
- The language service starts in the stored language, or in English when none is stored
- Switching the language changes the displayed texts and stores the choice
- A missing German key shows the English text

Done when the page is available in English and German, the choice survives a reload, and the tests are green.
